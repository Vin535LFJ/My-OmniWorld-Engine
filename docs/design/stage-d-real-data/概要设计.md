## 1. 本阶段目标与成果

**引擎第一次吃真实世界的数据，并第一次用 GPU 的方式吃。** 两件事互为表里：真实视频是"最少拷贝/同步/延迟"这个最初技术论点（ADR-0008 复位为本体，PLAN §二 ①）真正的用武之地——合成世界的观察是内存里画的，零拷贝无从证明；同时它也是**判据 (c) 欠账的唯一关闭路径**（阶段 A/B/C 三轮都卡在"真值与模型定义域不相交"，problem-log 012）。

出口一句话：**真实帧序列能作为观察源入环、真实标注能当评分基准、解码→推理路径的跨设备拷贝与延迟有实测上界。**

## 2. 裁决记录（两轮共创，2026-10-19）

### Round 1 · 主线与形态

1. **主线 = GPU 数据流（零拷贝）**，不是"能跑通就行"。owner 明确选择风险最高、主张最强的一条：解码 → 推理 → 世界状态更新全程显存驻留，逐阶段拷贝与同步可计量。**否决**："只做最小通路不背判据"（出口判据会变薄）、"只做真实入环 + 关闭判据 (c)、GPU 推迟"（把支点排到队尾）。
2. **真值 = 真实数据集的标注**，不再靠合成世界造答案。
3. **解码 = 直接上 FFmpeg / NVIDIA Video Codec SDK（NVDEC）**，不走"帧序列先行"的保守路线。**否决理由**（owner）：绕开真解码器就绕开了真问题。
4. **参考模式吃已解码帧，解码归性能模式。** 逐字节 oracle 与"参考模式零外部依赖"两条不变式因此**不被本阶段破坏**——与 ADR-0012 完全同构：新依赖关在默认 OFF 的可选构建里。

### Round 2 · 机制与边界

5. **真值落点 = TruthWorld 装载外部标注**，契约④⑤（单写者 / 唯一写路径）**零改动**。代码依据：`TruthWorld` 是具体类，`world_state.hpp:13` 用 `friend class TruthWorld` 把单写者钉在类名上；抽真值接口会动契约，必须先升 ADR。**否决**：抽接口（更干净但代价是契约变更）。→ TruthWorld 从"生成器"扩展为"生成器 + 装载器"。
6. **评分空间 = 观察归一化坐标（图像 uv）**。硬事实：真实视频只有图像坐标，没有相机标定就无法反投影回世界系，而现有 `matched_error` 比的正是世界 x/z。→ **本条需要一条 ADR（拟 ADR-0013）**：位置正确性从"世界空间"扩展到"观察空间"，语义由契约⑧（相机是观察的属性）背书。
   ⚠️ **必须是新增路径而非替换**：阶段 A/B 的世界空间基线哈希（`574361e62eec92b9` / `459ff85132cc103e`）与 `slice11/12/16` 的字面量是 oracle，替换语义会让它们全部作废（见 §7 R-D5）。
7. **数据许可 = 数据集不进 git**，只入库获取脚本 + SHA256 + 逐条许可记录（照 `tools/fetch_models.mjs` 的成熟做法）。代价如实承认：**"clone 即跑"对本阶段部分失效**，外部工件需自带取数步骤。
8. **D1 = 环境与依赖核验切片**（research note + 构建级证明），因为 GPU 主线现在直接依赖本机不具备的东西：CUDA EP 因缺 cuDNN 9 / CUDA 12.8+ 连载入都失败（C3/C4 两次实测）。

### 结构性决定（共创过程中浮现，未经投票，需 owner 在冻结时一并确认）

9. **判据 (c) 的关闭尝试不依赖 GPU。** 切片依赖图刻意让 D2（帧供给）→ D3（标注装载）→ D4（观察空间评分 + 判据重测）**全程可在 CPU 上完成**，只有主线 D5 依赖 CUDA/NVDEC 环境。理由：阶段 C 的教训是环境阻塞把两条判据拖成 PARTIAL；这次把"能关闭的判据"与"需要机器的判据"解耦，任何一台机器都不该阻塞另一条。

## 3. 模块划分与独立性论证

| 模块 | 本阶段增补 | 内聚 / 耦合论证 |
|---|---|---|
| `observation` | 新增**外部帧供给**：已解码 raw 帧序列 → `Observation`（`sensor_kind` 区分 `rgb_topdown` / `rgb_video`）；相机与分辨率仍是观察自带属性 | 观察仍是唯一"生产者视角"；只是多了一种生产者，且**参考模式的生产者零新依赖** |
| `truth_world` | 新增**标注装载**：逐 tick 的标注序列 → 真值实体集合；单写者与 friend 机制不变 | 真值权威不变，只是内容多一种来源；契约④⑤零改动（§2 条 5） |
| `metrics` / `adjudication` | 评分空间增加"观察归一化"模式；世界空间路径与基线**原样保留** | 唯一被允许改语义的地方，且**加法式**（§2 条 6 的⚠️）；需 ADR-0013 |
| `perception` | 现有两模型适配器复用；输入可以是真实帧 | 参与者不变式延续：真实数据不需要新适配器 |
| `loop` + `apps` | 性能模式接入解码器与 GPU 缓冲；逐阶段**拷贝计数 / 字节数**计量并入现有 per-stage 采样 | 编排者唯一；拷贝计量沿用契约⑨ 已有载体，不另立指标层 |
| 构建层 | 新增可选依赖（FFmpeg / Video Codec SDK），**默认 OFF**，与 `OW_WITH_ONNXRUNTIME` 并列 | 参考模式零外部依赖的构建级证明继续成立（ADR-0012 同构） |
| `tests` | slice17– | 行为 + 确定性成对（problem-log 002）；模型侧断言只断边界不断"零"（008） |

**耦合论证**：跨模块依赖仍单向汇入 `loop`；真实数据是**两个新生产者**（帧供给、标注装载）而不是新分层——现有契约的每个消费者都不知道数据来自真实世界，这正是"家族无关"（C4 已证）在数据维度上的推广。

## 4. 接口签名（C++20 级，草案）

```cpp
// ---- 观察源：已解码帧序列（参考模式，零外部依赖） ----
class FrameSource {                      // 新接缝，与 PerceptionAdapter 同族
 public:
  virtual bool next(Observation& out) = 0;   // false = 流结束；不抛异常控制流程
  virtual const char* name() const = 0;
};
// FileFrameSource：raw RGB8 文件序列 + 清单（宽高/帧率/色彩布局/起始 tick）
// 参考模式唯一允许的实现；解码器实现只在性能模式注册。

// ---- 真值装载：TruthWorld 的第二种内容来源 ----
class TruthWorld {
 public:
  void build_demo_scene(WorldState&, std::uint64_t seed);      // 既有，不动
  bool load_annotations(WorldState&, const AnnotationSet&);     // 新增：外部标注 → 真值
};
// AnnotationSet 来自数据集标注（归一化图像框 + 可选 3D/标定）。
// 单写者不变：只有 TruthWorld 能写 WorldState（friend 机制原样保留）。

// ---- 评分空间：加法式扩展，不替换 ----
enum class ScoreSpace { WorldXZ, ObservationUV };   // ADR-0013
// matched_error(...) 按 ScoreSpace 分派；默认 WorldXZ，
// 现有基线哈希与 slice11/12/16 字面量因此逐位不变。

// ---- GPU 数据流计量（性能模式） ----
struct TransferCounters {                  // 并入现有 per-stage 采样
  std::uint64_t host_to_device_bytes = 0, device_to_host_bytes = 0;
  std::uint32_t copies = 0, syncs = 0;
};
// 出口判据 (c) 的度量对象；参考模式下恒为 0（可断言）。
```

## 6. 非功能需求细化

- **参考模式零外部依赖不变**（延续 ADR-0012）：FFmpeg / Video Codec SDK 只在 `OW_WITH_*` 为 ON 时链接；OFF 构建不 include、不感知。
- **许可红线**（PLAN §五）：AGPL/GPL 一律不进产品路径；FFmpeg 取 LGPL 构建且**不启用** `--enable-gpl`（D1 逐条核验并记录实际构建参数）；数据集许可逐条记录，**不入库**。
- **确定性分层**：参考模式吃帧序列文件（字节固定 → 逐位可复现）；解码器输出**不进入**任何哈希（跨驱动/版本不保证一致）。
- **容差窗口**：每个 GPU 组件落地时按 L1 Round 1 #4 原则声明（实测最大抖动 × 2），写入 regression 报告。
- **计量优先**：任何"更快"的主张必须先有 `TransferCounters` + p50/p95 的实测行，否则不写进报告（AGENTS：没有 benchmark 数据不宣称性能）。

## 7. 风险登记

| # | 风险 | 缓解 |
|---|---|---|
| R-D1 | 环境不可控（cuDNN / CUDA 版本 / 驱动 / GeForce 解码会话数与格式限制） | 结构解耦：D2–D4 不依赖 GPU；D1 先出核验结论再动 D5 |
| R-D2 | FFmpeg / SDK 许可与分发条款踩线（含"静态链接触发 GPL"这类细节） | D1 research note 逐条核验 + 记录实际构建参数；不通过则不进产品路径 |
| R-D3 | 数据集许可与"clone 即跑 / 可公开展示"冲突 | §2 条 7：数据不入库 + 获取脚本入库；对外工件明确标注许可与取数步骤 |
| **R-D4** | **真实标注本身有噪声与协议差异**（遮挡/截断/每数据集不同标注规则），可能把"模型错"误判成"真值错" | 标注预处理规则写进 D3/D4 的 L2 并冻结；判据 (c) 报告必须附标注口径说明 |
| **R-D5** | **评分空间改动破坏阶段 A/B 冻结基线**（oracle 失效 = 整个可复现性主张崩塌） | 强制加法式：`ScoreSpace` 默认 `WorldXZ`；`slice11/12/16` 字面量必须继续逐位通过，否则视为回归缺陷（problem-log 002 的成对纪律） |
| R-D6 | 零拷贝收益被小分辨率、单帧串行、同步点抵消，实测可能不划算 | 判据 (c) 用**拷贝字节数与次数**而非只看延迟；不划算就如实报告（阶段 C 的 PARTIAL 先例） |
| R-D7 | 观察空间评分让"位置正确"失去物理含义（不同相机同一物体会得不同 uv） | ADR-0013 必须写清适用边界：观察空间判据只用于**同一观察序列内**的校准比较，不用于跨场景定位主张 |

## 8. 出口判据（能力 Gate，**待 owner 冻结时确认数值形式**）

| # | 判据 | 及格线（形式在此冻结，数值在对应切片实测后写入报告） |
|---|---|---|
| (a) | **真实数据在环可复现** | 同一帧序列 + 同一标注 + 同 seed → 观察哈希 / 账本哈希 / 指标三处逐字节复现；参考模式仍零外部依赖（OFF 构建全绿） |
| (b) | **判据 (c) 关闭尝试** | 真实标注面板上，诚实 vs 注入错误置信度的 per-producer ECE 分离量 **≥ 0.30** → 达标；否则如实 PARTIAL 并给出口径原因。**阈值不动**（006/007/012 三轮纪律） |
| (c) | **GPU 数据流（主线）** | **两个基线**（2026-10-27 owner 确认数值形式；此前单基线写法不可执行——CPU 路径的设备拷贝恒为 0，从 0 不可能再降 50%）：**B0**（CPU 全路径：CPU 解码 + ORT CPU EP + host 全程）→ 端到端**每帧 p95 延迟**相对下降 **≥ 50%**；**B1**（GPU 但有 host 往返：NVDEC → D2H → ORT CUDA EP）→ 跨设备**拷贝次数与字节数**相对下降 **≥ 50%**，且**绝对上界冻结为字面量**写进 regression 报告。零拷贝路径（Z）必须**同时赢过 B0 与 B1**。三组数据必须**同机、同视频、同模型、同分辨率、同帧数**。**阈值不动** |
| (d) | **不变式不退化** | 阶段 A/B/C 全部基线（含 `slice11/12/16` 字面量与 600/42 哈希）逐位不变；全量套件在**每一种构建配置**下都跑全（AGENTS 硬规则 #4） |
| (e) | **对外工件** | 视频管线工程笔记 + 阶段 D regression 报告（环境元数据 + 模式 + 拷贝分解 + 数据集许可声明） |
