## Decision

### D1 定位 v2（Q2 终裁）

1. **不变**：ADR-0008 引擎身份、PLAN §三终局画面、§四三层目标函数、契约九条语义、ADR-0009 双模式、Gate 体系、阶段 D 照常（D5 零拷贝继续）。
2. **定位表述升级为双句**：**对外定位 = 可测量的世界状态运行时**——canonical 状态契约 + 真值/信念分离 + 逐 tick 在环评分 + 位级可复现 episode；"基准之下的运行时"，不是又一个 benchmark。**工程属性 = GPU 原生数据流纪律保留**——最少拷贝/同步/延迟仍是硬主张，D5/D6 是其兑现，不被降级。两者是同一本体的两面。
3. **四层为逻辑分层**（L1 理解 / L2 构建 / L3 运行 / L4 表现 + 横向 World Contract 与 GPU Observability），不代表执行顺序；**本体 = L3 心脏 + 横向契约与测量**；L1/L2/L4 是可替换的生产者与表现座位。
4. **六方向 = 六类座位，不是六个并行项目**（生成式世界模型/视频生成/具身仿真/程序化生成/重建空间智能/渲染 GPU，映射见六方向整合 note §4）。L2 是四层中唯一真正新增的层，治理见 D4。
5. **隐含终裁 11-05 三问**：Q1 = 开发者运行时（创作产品仅下游期权）；Q2 = 混合式（生成式进数据/表现，结构化进状态）；Q4 = 评测闭环为第一应用。Q3（第一批用户）不终裁——仍是期权触发器问题，外部信号出现才启动。
6. **"它不是"清单追加**：不是又一个 benchmark（做基准之下的运行时）；不是场景生成器产品（生成器是受契约管理的座位资产）。原有三条（游戏引擎/大模型本体/工业数字孪生）不变。

### D2 首战 B'：程序化真值世界工厂 × 生成式模型闭环考场（Q3+Q7 终裁）

**用户可见结果**：一条命令生成带真值的小世界（集装箱堆场：每箱权威身份/位置/碰撞体，事件有真值时钟）→ 一个开源生成式世界模型经适配器入环，跑"镜头转开→事件发生→镜头转回"episode → 报告回答四问（恒存/事件推进/身份漂移/置信度校准），同 seed 逐字节复现。

**验收判据（阶段 E 出口，五条）**：
- **(a) 真值世界工厂**：参数化 + seed，生成器输出几何+碰撞体+语义+置信度+版本，同 seed 逐字节（参考模式）；内容经 TruthWorld 装载，**单写者不动**（与 Annotation Truth 先例同构）。1–2 个生成器起步，不做通用 PCG 平台。
- **(b) 闭环考场**：≥1 个开源生成式世界模型经适配器入环，**核心零改动**（阶段 C 判据复用）；模型输出 = Proposal，不写真值。
- **(c) 四问报告**：per-producer ECE 带 Claims 分母；**M1 成对发布 / M2 空集排除 / M3 per-producer 分解**强制继承（E1 定案）；转开题必须 judgeable（NA 语义，参照 WRBench gate 与 MemoBench motion-gated）。
- **(d) 位级复现（录制-回放锚定）**：真实生成模型天然非确定，参考模式不直接含它。**位级 oracle 锚在真值世界 + 引擎裁决账本**；模型输出在性能模式录制一次，参考模式以录播回放作为确定性生产者重放 episode（回放逐字节）。外观生成侧不承诺位级（Marionette 同机位级/跨机分叉实证边界，知识基线 T7）。与 ADR-0009 双模式一致。
- **(e) 外部工件（作品集 Gate）**：带环境元数据的 benchmark 笔记 + clone 即跑 + 一页工程笔记；报告必须展示**至少一个"只有 OmniWorld 能测"的指标**（09-21 风险 #3 判据；候选：无观察期间事件推进正确率——需真值事件时钟 + 在环评分，批处理视频基准给不出）。

**降级路径**：8GB 标的全部出局且离线不可行 → 保 (a)(c)(d)(e)，(b) 换确定性 stub，如实标注"无真实生成模型在环"。
**边界**：考场不是游戏产品（无玩法/HUD/玩家），不踩 PLAN ⑤让渡行；日后可玩场景（选项 A）须显式复议。
**前置顺序**：ADR-0017 裁决（✅ 同日）→ 8GB 标的逐卡核验（ForgeWM 优先：Wan2.1-1.3B 底座、代码+权重+数据全开放、Apache-2.0，推理显存未公布是唯一缺口）→ 本 ADR → L1 共创 → 切片。

### D3 排序（Q8 终裁）

**工程串行 + 研究并行**：D5/D6 代码线照常（GPU 纪律是 v2 工程属性，不停）；B' 前置研究（标的核验、生成器契约 L1 共创）走 Intelligence 轨并行，不占 D5 代码资源；**B' 代码切片在 D6 收口后开工，编号阶段 E**。智驾里程碑（D5 节）排 E 首份报告之后。

### D4 L2 治理（Q9 终裁）

1. **生成器契约语义**（参数→几何+碰撞+语义+置信度+版本）经本 ADR + L1 设计进 CORE；遵守"每个字段必须有真实消费者、只加字段不改语义"。
2. **首个生成器**（堆场）作为 B' 切片实现；验收权在**规则验证器**（穿模/法线/碰撞一致性/比例）；AI 写生成器允许（Saltline 路线），AI 自评不算验收。
3. **通用生成器库平台、编辑器、玩法**仍 BACKLOG/⑤让渡。
4. L2 不触现有红线（程序化几何为 CPU 轻计算）；Vulkan 后端按 D5 条件解封走。
5. 动画座位复用侧项目结论；引入任何组件仍需另立 ADR。

### D5 智驾处置（Q5 终裁；原"ADR-0015"在途编号作废，并入本 ADR）

**选项①为主 + ③为其 L4 后端候选；②明确否决。**
- **①** = 通用"视频→场景重建→自由视角渲染"能力：L1 重建生产者座位（VGGT 类前馈重建输出点图/相机/深度，经 Proposal 进契约，置信度语义引擎归一化）+ L4 自由视角表现。**AD 视频只是第一个数据域，不是产品方向**——PLAN ⑤"AD/ADAS 产品方向"让渡行不动。素材全 NC → 整链只能非商业研究形态，数据不可再分发。
- **③** = 离屏 Vulkan 观察渲染器（族谱③技能座位）作为 ① 的 L4 后端候选。
- **②否决理由**：重开⑤让渡、16GB+ 竞争压顶、8GB 撑不住产品叙事。

**三条红线条件解封（逐条，不一揽子放开；CURRENT"不碰"清单同步措辞）**：
1. **多相机与位姿估计** → 解封为"消费外部重建生产者输出的位姿/标定产物"（VGGT 出相机参数，引擎按 Proposal 裁决）；**自建多相机标定求解器仍封**（BACKLOG）。
2. **3D 反投影与标定求解** → 同上：反投影经生产者点图消费；自写标定求解仍封。
3. **GPU 渲染器与 Vulkan 观察后端** → 按族谱③技能座位解封，条件：参考模式 CPU 光栅器仍是唯一位级 oracle；Vulkan 只进性能模式；位级主张锚在状态/几何层；进产品路径前按证据回归。

**第一个可测量里程碑**：一段 Argoverse 2 log → VGGT-Ω → gsplat → 自由视角渲染 + PSNR/SSIM/延迟进回归报告。**前置硬门 = 本机 8GB 实测 spike**：Ω 官方端到端显存表 25 帧 7.80GB = 8GB 的 97.5%（A100 口径；Robot_Learn 事实底本总表第 65 行，2026-11-14 落库），旧"≤20 帧 5.58GB 可行"档作废；实测不过则降级更短片段或 CPU 离线档。排序：E 首份报告之后。

### D6 动画现状确认（Q6 终裁）

角色动画路线维持 2026-10-27 亲裁：独立项目、不入引擎产品路径、不占阶段 D 资源、定仓库后整体迁出。唯一增量：将来 L2 建层时其"运动数据层与 World Contract 同构"结论与程序化 IK 座位可复用（**复用结论 ≠ 引入组件**，引入仍需另立 ADR）。不新增承诺。

### D7 术语（Q10 终裁，GLOSSARY 已同步）

新增四条：**World Producer（世界生产者）**、**Procedural Truth Source（程序化真值源）**、**Exam Episode（考场回合）**、**Generator Contract（生成器契约）**；四层逻辑分层加指针级词条（实现细节在本 ADR 与 L0，不入 GLOSSARY）。GLOSSARY 头部定位句同步 v2 双句。
