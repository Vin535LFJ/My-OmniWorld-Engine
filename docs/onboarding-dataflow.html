点击顺序即数据顺序。"不变式"一列是它对外承诺、且被测试钉住的东西。
环节职责不变式 / 证据
真值世界
truth_world		引擎独占作者权的种子确定性运动学世界，8 个实体在 y≡0 平面上常速运动。所有"信念"以它为评分基准。同 seed 逐字节复现。600 ticks / seed 42 → world_hash 574361e62eec92b9，阶段 A 至今未变。
观察
observation		某 tick 的有界视图：RGB 帧 + 自带相机（位姿与分辨率）+ 每实体三态可见性。分辨率是观察的属性而非全局常量（32/64/518/640 实测通过）；"未见" ≠ 空值 ≠ 零。
参与者
perception/*		4 个自注册适配器文件：2 个内建 CV 检测器、RT-DETRv2-S（真实检测）、DA-V2-Small（真实深度）；另有 2 个世界模型走同一接缝。单文件接入、核心零分支；适配器只读观察、不得铸类别标签。
Proposal
core/proposal		非所有者唯一的写路径：谁 / 何时 / 哪个实体 / 主张什么 / 多确信。契约⑦：置信度是 [0,1] 自报标量，零裁决权力，唯一消费者是校准指标。
裁决
adjudication		编排者独占的冲突消解：schema 校验 → 位置容差 0.1 关联真值 → Applied / Announced / Rejected。并列按 id 序消解（确定性）；NewEntity 只是"宣布"，世界 id 只能由真值路径产生。
信念账本
belief/ledger		追加式存储，主张连同裁决一起留档。错误是数据，永不覆盖。600 ticks ≈ 9 746 条。
指标
metrics		divergence、ECE（按生产者分表）、身份稳定性。聚合 ECE 会被产量最大的分量绑架，故分表是必需视角（problem-log 005）。
运行工件
loop/driver		确定性 JSON：config + 环境元数据 + 逐阶段 p50/p95 + 双哈希 + first_fault。不含墙钟与随机；性能模式有参与者故障 → 非零退出码，但工件照常写出。
