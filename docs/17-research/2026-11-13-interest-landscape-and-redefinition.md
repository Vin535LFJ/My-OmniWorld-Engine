## 0. 结论摘要（先看这五句）

1. **你的兴趣不散**：大模型、具身机器人、世界模型、渲染管线、引擎、实时交互模型、视频生成——全部在同一条链上：**理解 → 构建 → 运行 → 表现 → 行动**，每项技术只是占位不同。
2. **真正的分叉只有一个**：世界状态放在**显式结构**里（可编辑、可测量、可复现），还是放在**隐式权重**里（丰富、但会漂移、难审计）。你列的每对"路线之争"（GPT+Blender vs Genie、鱼眼拼接 vs 生成式仿真、VLA vs WAM）本质都是这个分叉在不同链段上的投影。
3. **头部玩家正在收敛到"混合"**：显式管正确性、生成式管丰富度。Genie 4 官方架构就是"Gemini 当导演 + Genie 当渲染器"的混合世界模型；生数 Motus2 把策略/模拟器/评估器放进同一套参数；你材料里的行业共识"引擎管状态逻辑 + 生成模型管视觉"是同一句话。
4. **混合方案缺的那块拼图 = 两半之间的状态契约与正确性测量**——而这恰好是 OmniWorld 已经建成的东西（World Contract 九条语义 + grounding 指标 + 双模式可复现）。Genie 4 官方承认的"物体出画再回来就变了"，正是没有外部状态锚的症状。
5. **重定义提案（待裁决）**：不是推翻引擎重做，而是把 OmniWorld 从"感知模型的评测运行时"升级为**混合世界的状态心脏**——任何世界生产者（AI 程序化生成器、生成式世界模型、真实视频重建、物理仿真器）经同一契约接入，引擎负责身份/时间/所有权/置信度与正确性测量，表现后端可替换。四层提案中真正新增的只有 L2（资产生成）一层。

## 1. 梳理框架：一条链、一个分叉、一个共识

### 1.1 一条链：世界的五段生命周期

```
理解(L1) → 构建(L2) → 运行(L3) → 表现(L4)
   ↑                                  │
   └──────── 行动(A) ←────────────────┘
```

- **理解**：从视频/图像/传感器得到结构化世界描述（这是什么、在哪里、什么属性）。
- **构建**：得到可复用的世界资产（几何、材质、骨骼、碰撞体、布局规则）。
- **运行**：世界按规则持续演化（时间推进、事件、状态转换、物理约束）。
- **表现**：把世界状态变成画面/视频/传感器观测。
- **行动**：智能体在世界里做事，结果反馈回理解。

这与生数朱军的"理解—想象—行动"闭环（已核，§3）、World Labs 的"渲染器/模拟器/规划器"三分法（转述）、以及**本仓库 grounding loop（observe → Proposal → 裁决 → 指标）是同一个骨架**。你之前提出的三层（理解/生成/渲染）缺的正是 L3——而 L3 恰是 OmniWorld 已有的心脏。

### 1.2 一个分叉：世界状态放在哪里

| 维度 | 显式结构化世界 | 隐式生成式世界 |
|---|---|---|
| 状态载体 | 几何 + 实体 + 规则 + 版本 | 模型权重 + 逐帧像素 |
| 可编辑性 | 数值级精确（坐标/尺寸/参数） | 语义级（"加一个人""改天气"） |
| 可测量性 | 可对真值逐字段评分 | 只能看画面像不像，状态藏权重里 |
| 可复现性 | 同 seed 逐字节（参考模式已做到） | 同 prompt 不保证同世界 |
| 丰富度成本 | 自然场景/人脸/表演动画极贵 | 一句话即得，边际成本低 |
| 典型失效 | 穿模、法线错、碰撞体与视觉不一致 | **物体恒存性漂移**、物理违规、长时不一致 |
| 代表 | Saltline 程序化、Blender/UE、AVM、Marble 重建 | Genie 4、Vidu S1、Cosmos、GAIA-2 |

**关键证据（已核）**：Genie 4 官方"当前局限"自认——短时会话连贯，但视觉细节与**物体恒存性随时间漂移**，复杂物理交互、空间精度仍是研究问题；演示中"城堡出画再回来多了一座""胸像按重力该倒却立着"。这说明隐式世界**需要外部状态锚**才能用于测量、导航、机器人仿真等"结论不能错"的场景。

### 1.4 用这张图回答你材料里的四组"概念辨析"

1. **视频生成 vs 世界模型 vs 实时交互模型**：不是三个赛道，是链上位置递进——L4 出画面 → L3 维持状态并预测 → L3 实时接受输入持续演化。"世界模型"的判据不是画质，是**能否回答"如果我改变条件，世界会怎样"**（反事实推演）。
2. **VLA vs WAM**：都在 A 段。VLA 感知→动作直映（快、长程规划弱）；WAM 先想象未来状态再出动作（Motubrain/Motus2）。两者互补，融合点=世界模型给 VLA 提供训练环境与长程推演——这正是[交互闭环路线 note](2026-10-27-interactive-closed-loop-route.md) 已登记的 Phase 4 座位。
3. **GPT+Blender vs Genie**：L4 的两条生产方式。前者经显式 L2/L3（数值级可控、可复用工程文件、回合制编辑交互）；后者端到端跳过 L2/L3（语义级控制、像素即产物、流式游玩交互）。**"编辑交互"和"游玩交互"不是同一种交互**——你材料里这个区分是对的，且正好对应引擎的两个座位：编辑=对世界状态的 Proposal 写路径，游玩=行动适配器。
4. **鱼眼拼接 vs 生成式仿真**：真实观测的几何重构（无幻觉、无预测、量产成熟）vs 生成式重建（任意视角、可预测、有幻觉、云端为主）。[智驾调研](2026-11-08-autonomous-driving-visual-survey.md)已逐页核验并给出本地 8GB 可行性分层，**只链接不复述**；你新材料里"小鹏 X-World / NVIDIA OmniDreams 原生鱼眼世界模型"说法**未核**（§6），若属实是 ADR-0015 的新证据。

## 2. OmniWorld 盘点：你已经手里有什么（行为语言）

| 已有能力（用户可见行为） | 证据 |
|---|---|
| 一个会裁决"谁在什么时候说了什么、该信谁"的活世界状态 | World Contract 九条语义（L0 §2 冻结）；单写者、字段所有权、置信度 |
| 任何模型经同一接缝接入，核心零改动 | 阶段 C：RT-DETRv2-S / Depth-Anything-V2-Small 两个真模型同契约入环 |
| 真实视频帧 + 真实标注已经在环里跑 | 阶段 D2/D3：COCO 200 帧面板，逐 tick 真值 |
| 能测量"这个世界生产者诚实吗/准吗"，且同 seed 逐字节复现 | per-producer ECE 分离、divergence、coverage；参考模式位级 oracle（ADR-0009） |
| GPU 数据流纪律（最少拷贝/同步/延迟） | D5 进行中；H2D 实测 12.81 GB/s，收益在减少往返 |
| **缺**：从一句话/一份描述**创造**世界资产的能力（L2） | 现状只有合成真值世界 + 真实标注，无生成器 |
| **缺**：像样的表现后端（L4） | 现状 CPU 光栅器参考组件；Vulkan/生成式后端在"不碰"清单，按证据回归 |

**一句话：你已经有"世界的心脏和秤"，缺的是"世界的工厂和脸"。** 四层提案不是从零造四层，是给已有的 L3 心脏补 L2 工厂、换 L4 的脸。

## 3. 竞争核实（2026-11-13 联网，逐条标核验状态）

### 3.1 Omniverse Agentic SimReady —— 已核（官方博客检索全文）

NVIDIA 2026-09-16 官方博客《How to Use AI Agents to Prepare 3D Scenes for Simulation》：Codex/Claude 编排 + NemoClaw 子代理 + Omniverse Libraries（ovphysx 物理 / ovrtx 渲染预检）+ Blender MCP 检查场景 → OpenUSD 承载契约 → SimReady 验证作为验收门 → 交付 Isaac Sim / Isaac Lab。**"AI Agent 自动把场景准备成仿真就绪"已被 NVIDIA 完整覆盖**，且 OpenUSD 就是它的契约层。

**对 OmniWorld 的含义**：不能以"AI 自动生成/准备场景"为差异化。但注意它的边界——机器人仿真向、绑定 NVIDIA 硬件与 Isaac 生态、面向"把已有美术场景补全成 SimReady"，**不是**"跨生成式/显式两种世界的通用状态运行时 + 正确性测量"，也不是本地免费 clone 即跑。你材料里"什么证据会改变判断"的答案：若 Omniverse Libraries 开放出免费本地通用运行时，应转向为其生态做扩展——目前证据不支持。

### 3.2 Genie 4 —— 已核（多方检索全文互证；官方一手 URL 见 §6）

2026-10-27 研究预览：一致性时长约 2 分钟（前代两倍）、原生音频、自然语言实时改世界（天气/视角/加人加物）、Gemini 3.8 Flash 在回路当"导演"拆解任务并逐帧检查、Gemini 4 Argon + Genie 4 模拟 Apollo 人形机器人下跳棋。官方自认局限：物体恒存性漂移、复杂物理、空间精度、文字可读性。**"混合世界模型"（语言模型规划 + 生成模型渲染）是官方明示方向**——与本文 §0 判断 3 互证。开放形态：受邀测试 → AI Ultra 订阅 → API 早期伙伴；**无公开程序化端点**（与 [`projects/genie-4.md`](projects/genie-4.md) W04 核验一致）。

### 3.3 生数科技 —— 已核（官网 WAIC 2026 新闻两篇检索全文）

- Vidu S1：实时流式交互生成，540P / 最高 42FPS，无限时长连续对话（数字人场景）。
- Motubrain（2026-04）：世界动作模型，MoT（Mixture-of-Transformers）统一架构——理解专家/生成专家/行动专家共享注意力，同一底座既出像素也出动作；RoboTwin 2.0 随机环境 50+ 任务平均成功率 >95%（官方口径）。
- Motus2：策略/模拟器/评估器三接口共享参数，"行动前预演、行动后自进化"，轻量触觉专家补接触最后一厘米。
- 朱军团队《General World Models from First-Principles》：理解—想象—行动闭环 + L1 生成世界 → L2 交互世界 → L3 行动中 → L4 自主智能体 → L5 世界组织者五级路线。
- **未核（用户提供）**：B 轮近 20 亿、ARR 2000 万美元、Vidu Q3 Artificial Analysis 全球第一、Motus2 外滩大会发布细节。不作为裁决依据。

**含义**：头部在做"统一基座"（一个模型包办理解/想象/行动），**不是"跨模型的状态运行时"**。OmniWorld 不与基座竞争，做基座们共同缺少的状态锚与秤。

### 3.4 Saltline / 几猫 —— 已核（GitHub 镜像 README 检索全文 + 报道互证）

- 原作 Saltline：Anthropic 工程师 Felix Rieseberg 用 Claude Fable 5.2 单 prompt 自主运行约 8 小时（445M 输入 / 2.7M 输出 token，约 $550，作者自述非审计），1.4MB 单 HTML，Three.js r180，模型/材质/音效全部代码生成；作者后续约 2 小时人工打磨。
- 几猫 = 汉化换皮：约 6200 行只改约 100 行，移除原作者署名、加"国产自研 3A"文案；源码仍留 SALTLINE 痕迹。
- **矛盾登记**：某技术栈文章称"禁用 Three.js、纯 WebGL2 从零光追"——与镜像仓库（明确打包 three r180）矛盾，以镜像一手证据为准；该说法可能混入了另一个 demo（castaway screensaver）。
- **含义**：证明 AI 能自主写出整套程序化生成器（L2 可行性），但产物是**一次性 demo**——无复用系统、无状态测量、无正确性验收。这正是"生成器作为可版本化、可测量资产"的机会位。

### 3.5 行业整合信号 —— 转述（媒体，未逐页核一手）

AMD 约 82 亿美元收购 World Labs（2026-09-28）、亚马逊洽谈约 70 亿收购 Decart、Rivian 收购 Third Dimension（2026-10-22，用于智驾仿真）、Runway GWM Worlds 2（2026-09）。**世界模型已成巨头战略资产**——独立做"生成世界"没有胜算，做"测量与锚定生成世界"的独立工具层仍有空间（与 research-queue 的 WorldFoundry 盯防条互为印证）。

### 3.6 竞争结论

**不做差异化**的三件事：AI 自动准备场景（Omniverse 已覆盖）、生成画面（Genie/Vidu/Runway 已产品化）、文本/图像→显式 3D（Marble 已覆盖，且被 AMD 收购）。
**缺口**：跨显式/隐式两种载体的**统一状态运行时 + 正确性测量**，本地、免费、clone 即跑、可复现。这与 [智驾调研 §5](2026-11-08-autonomous-driving-visual-survey.md)"两域割裂正是机会位"、research-queue 定位主张（state-centric real-time loop vs model-centric batch pipelines）三方互证。

## 4. 重定义提案（供 grill → ADR 裁决，不是决定）

### 4.1 新一句话定位

> **OmniWorld 是一个可测量的世界状态运行时：任何世界生产者——AI 程序化生成器、生成式世界模型、真实视频重建、物理仿真器——经同一份契约接入；引擎负责身份、时间、所有权、置信度与正确性测量；表现后端可替换。**

与 ADR-0008 的关系：**引擎身份不变，变的是生产者集合**。原来生产者=感知模型+合成真值；现在扩展为四类。评测仍是第一应用，但评测对象从"感知模型"升级为"任何世界生产者"（含生成式世界模型的状态一致性）。

### 4.2 四层提案的落地映射

| 层 | 现状 | 提案 |
|---|---|---|
| L1 理解 | 适配器机制已验证（两真模型零核心改动） | 不动；重建类生产者（VGGT→gsplat）按 queue 证据回归 |
| L2 构建 | **空白** | 新增：AI 编写程序化生成器 + 规则约束验证 + 生成器版本化。生成器本身是可测量资产（Saltline 教训：一次性 demo 无沉淀）。混合式：AI 出初稿，规则管约束/修正/验证 |
| L3 运行 | **已有心脏**（契约+裁决+闭环） | 不动语义；新生产者经 Proposal 写路径接入，单写者与契约④⑤不碰 |
| L4 表现 | CPU 光栅器参考组件 | 座位保留：GPU 渲染器 / 生成式视频后端按证据回归（现"不碰"清单需 ADR 复议才动） |
| 横向 | World Contract + 延迟/拷贝计量已有 | 即四层提案的"World Contract + GPU Observability"，无需新发明 |

**世界真实性与视觉表现解耦**（你材料的核心原则）= 本仓库"参考模式/性能模式"双模纪律的自然延伸：状态正确性由契约与指标保证，画面质量由可替换后端负责。

### 4.3 与既有决策/在途事项的关系

- **阶段 D（D5/D6）**：不受本 note 影响，照常推进。本文不改 CURRENT。

- **交互闭环路线（Phase 4 候选）**：WAM/VLA 适配器座位与本提案完全兼容，无需重开。

### 4.4 第一个验证场景：三个候选（行为语言）

| 场景 | 用户可见结果 | 验证什么 | 代价/风险 |
|---|---|---|---|
| **A 一句话→可运行雨夜港口** | 输入一段描述，得到机械狗巡逻、叉车运箱、碰撞正确、任务事件可计数的可运行世界；画面可切低配/高配 | L2+L3+L4 全链协同；作品集冲击力最强 | 工作量最大；踩游戏让渡行；L4 需复议"不碰"清单 |
| **B 生成式世界模型的状态一致性评测** | 把一个开源视频世界模型插进引擎，跑"镜头转开再转回，物体还在不在/身份漂没漂/物理违没违"，出可复现报告 | 缺口最直接（Genie 4 官方局限=现成靶子）；改动最小（现有指标+新生产者适配器） | 依赖 8GB 可运行开源标的（Genie 闭源、Cosmos 16GB 已出局；MineWorld/Matrix-Game 类待逐卡核验，W04 在途） |
| **C 真实视频→结构化世界→新视角重渲染** | 喂一段真实视频，得到可查询的世界状态，再从别的视角渲染出来 | 真实世界输入半边；与智驾调研衔接 | 红线最多（多相机/标定/GPU 渲染器）；必须与 ADR-0015 同裁；8GB 只能离线短片段 |

**本文推荐（仅推荐）**：B 为主线候选（离已有资产最近、缺口最直接、不踩让渡行），A 作为技能/作品集侧线（程序化实验室，先不入产品路径），C 并入 ADR-0015 统一裁决。理由：目标函数第一层是技能阶梯、第二层是敲门砖——B 产出"别人没有的测量报告"，A 产出"看得见的程序化资产库"，两者都服务作品集且不互相阻塞。

### 4.5 什么证据会推翻本提案

1. WorldFoundry"comprehensive update"（queue 盯防条）若已提供跨生产者状态契约+正确性测量 → 转向为其生态贡献，不独立造。
2. 8GB 可运行的开源交互世界模型长期不存在 → 场景 B 无标的，降级为 A 或 C。
3. Omniverse Libraries 开放免费本地通用运行时 → 重估 build-vs-integrate。
4. 若发现"状态锚定生成式世界"已有成熟开源方案（如某 world-state register 项目落地）→ 同上。
