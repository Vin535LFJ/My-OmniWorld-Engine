# deep/ — 深度调研报告（W04 深度层）

> W04 生态调研的**深度层**：每个 Tier 1 项目一份深度报告，与 [`../projects/`](../projects/) 的事实卡互补——
> **卡管"是什么/许可/硬件/边界"，深度报告管"它怎么做到的"**（架构、算法、数据流、关键取舍）。
> 系列总摘要与导航：[`../2026-11-05-deep-research-index.md`](../2026-11-05-deep-research-index.md)。

## 约定

1. **文件名带日期**（`2026-11-05-<slug>.md`）：深度报告是一次性深潜，不是活文档；项目演进时另起新日期的报告，旧报告不删。
2. **结构与纪律**与项目卡相同：Trust label 头、一等来源（论文原文/官方技术文档/官方源码）、每条机制性陈述附 URL 与检索日期、核验不了标 **UNVERIFIED**。
3. **与事实卡去重**：许可/显存/平台等事实一律链接到卡，不复制；报告只写卡的 §1/§2 装不下的原理层。
4. **闭源项目红线**：只讲官方公开的原理（官方博客/文档/论文），不臆测内部实现；臆测必须显式标注"推断"并说明依据。
5. **来源分层标注**：论文原文 > 官方技术文档 > 官方源码 > 官方博客公告；二手转述不进正文。
