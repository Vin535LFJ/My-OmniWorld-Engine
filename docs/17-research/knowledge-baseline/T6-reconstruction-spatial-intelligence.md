## 1. 原理与技术路线分类（本节最厚实）

### 1.1 多视图几何基础：一切重建路线的共同底座

**针孔投影与对极几何。** 相机把 3D 点 X 投到像素 x：`x ≃ K[R|t]X`（K 内参：焦距/主点；[R|t] 外参）。同一物理点在两视图的像素满足对极约束 `x'ᵀ F x = 0`（F 基础矩阵；归一化坐标下为本质矩阵 E = [t]×R）——它把"找对应点"从 2D 搜索降为沿对极线的 1D 搜索，是特征匹配与三角化的几何前提。**三角化**：已知两相机位姿与一对对应像素，两条视线交点即 3D 点；基线越短、视线夹角越小，深度不确定度越大（这是双目/多目深度误差随距离平方增长的根源）。**PnP**：已知 3D-2D 对应反解相机位姿。以上为标准教科书内容（Hartley & Zisserman 体系；DUSt3R 论文 §2-3 对经典管线的刻画可作对照，[arXiv 2312.14132](https://arxiv.org/abs/2312.14132)，已核）。

**Bundle Adjustment（BA）。** 本质是**在参数空间迭代最小化重投影误差**的非线性最小二乘：`min Σ ‖π(K, R_i, t_i, X_j) − x_ij‖²`，同时精化全部相机参数与 3D 点；用 Gauss-Newton/LM 反复"线性化-解增量"，配鲁棒核抑制误匹配。特性：对初值敏感、需要充分跨视图匹配观测、逐场景求解、收敛后可非常准。COLMAP 是"匹配→增量 SfM→BA→稠密 MVS"多阶段管线的代表实现（VGGT 深报 §2.9 已核对照：10 随机帧 COLMAP+SP+SG 约 15 s，AUC@30 在 Re10K 仅 45.2——弱纹理/重复纹理/少视图是其结构性失败模式）。

**SLAM = 在线化的同一几何。** 视觉 SLAM（ORB-SLAM 系特征法、DROID-SLAM 系稠密法）把 SfM 拆成逐帧 tracking + 增量 mapping + 回环校正，核心仍是重投影/光度误差优化；与前馈重建的本质差别是**有递归状态、有时间轴**（这一点对世界状态运行时语义重要，见 §1.3）。

**尺度规范（gauge）——理解一切"3D 输出"的钥匙。** 单目图像序列在任意相似变换（旋转+平移+全局缩放，7 自由度）下重投影不变：重建结果只能确定到 Sim(3)，**绝对尺度不可观测**。各路线的规范选择：
- COLMAP/BA：钉死首相机 + 任意尺度（或靠已知基线/标定物定标）；
- VGGT：输出钉死在**首输入帧相机系**，训练时 GT 按"点图到原点平均距离"归一化尺度（深报 §2.2/§2.8 已核）；
- π³：**取消参考帧**，预测仿射不变相机位姿 + 尺度不变局部点图，全序列共享一个未知尺度因子（官方 README，已核，§2.1）；
- 单目深度网络：affine-invariant 深度（只保证相对结构）或靠内参先验回归 metric 深度（§1.5）。
**共同结论：没有任何视觉重建模型输出"持久世界坐标"——坐标系与尺度的所有权天然在使用方。** 这与 World Contract 的 canonical frame 所有权问题是同一个数学事实（关联，非裁决）。

### 1.2 三条技术路线：优化式 vs 前馈式 vs 生成式

| 维度 | 优化式（COLMAP/SLAM/BA） | 前馈式（DUSt3R→VGGT→π³/DA3/Ω） | 生成式（扩散/自回归世界模型） |
|---|---|---|---|
| 计算形态 | 逐场景迭代优化 | 一次前向推理（摊销） | 条件采样（去噪/自回归 rollout） |
| 几何先验来源 | 无（只信当前观测） | 训练数据分布（17 类~2M 序列） | 训练数据分布 + 生成先验 |
| 输出性质 | 观测一致的测量解 | 观测近似的回归解（带置信度） | 分布内"合理"的想象解 |
| 失败模式 | 弱纹理/匹配失败→无处着落 | 分布外几何（鱼眼/极端旋转/大幅非刚性） | 幻觉、身份漂移、事件不推进（WRBench 病灶） |
| 精度上限 | 收敛后可很准 | +BA 后处理才是上限（VGGT+BA IMC 84.91 vs 纯前馈 71.26，深报 §2.9 已核） | 不以测量精度为目标 |
| 时间语义 | SLAM 有递归状态 | 每场景一次快照，无增量接口 | 自回归有 KV 状态，但状态是隐式的 |

**前馈式的原理核心 = 摊销（amortization）**：把"匹配-三角化-优化"的复合映射在海量带 3D 标注数据上端到端压进网络权重。三个使能机制（VGGT 深报 §2 已核，此处只提原理骨架）：① GT 归一化把回归目标钉成唯一规范解（消 gauge）；② 交替帧内/全局注意力承载跨帧"对齐"；③ 多任务过完备监督（相机/深度/点图/轨迹互相校准）。谱系：DUSt3R（图对点图回归 + **测试时全局对齐**，仍含优化）→ VGGT（任意帧数、无测试时优化）→ π³（去参考帧、置换等变）→ DA3（单一 plain transformer + depth-ray 最小表征）→ VGGT-Ω（规模化：0.2B→10B、2K→2M 序列，误差单调下降，官方摘要已核）。**优化没有被消灭，只是被移出推理路径**——需要更高精度时官方自己的答案仍是回到 BA（VGGT `demo_colmap.py --use_ba`）。

**生成式重建的原理与边界**：不求解"与观测一致的几何"，而是从条件分布采样"看起来合理"的补全/演化。两种形态：① 前馈新视角合成（FF-NVS）：几何基础模型 + 3DGS 参数头，一次前馈出可渲染表示（DA3 论文建立 160+ 场景 FF-NVS 基准，并证明几何重建能力与 NVS 质量正相关——官方论文已核；pixelSplat/MVSplat/DepthSplat/AnySplat 等专门模型见其 related work，转述）；② 驾驶世界模型：动作条件视频生成（Vista/GAIA-2/X-World/OmniDreams，§2.3）。**对世界状态语义的关键区别：重建输出是"测量候选"（可带逐像素置信度、可与 GT 对账），生成输出是"信念/Proposal"（无测量语义，恒存性与身份不保证）**——六方向整合 §2 相通性矩阵已把生成式模型定位为"输出=Proposal，不是真值写"（仓库已核，只链接）。

### 1.3 3D Gaussian Splatting：表示、光栅化、训练

**表示。** 场景 = 一组各向异性 3D 高斯，每个带：位置 μ、协方差 Σ（分解为缩放 S 与旋转 R，Σ = RSSᵀRᵀ 保证半正定）、不透明度 α、球谐（SH）系数表达的视角相关颜色。显式点基表示——与 NeRF 的隐式 MLP 相反，可编辑、可增删、可局部变换（这是驾驶场景"静态背景+动态前景分解"能做的前提）。

**渲染 = 可微 tile-based 光栅化（非光线步进）。** 3D 高斯经投影变换的 Jacobian 近似投成 2D 高斯（EWA splatting）；屏幕分 tile，每 tile 内按深度排序，前到后 α-blending 累积颜色与透射率。整条管线可微 → 可用光度损失端到端优化。实时性：论文口径 1080p ≥30–100+ fps（智驾综述 §3 逐页核验 ✅，[arXiv 2308.04079](https://arxiv.org/abs/2308.04079)）。

**训练 = 逐场景优化。** 输入带位姿图像（传统来自 COLMAP；现在可来自 VGGT 直出，官方 gsplat==1.3.0 集成示例已核——VGGT 卡 §5），从稀疏点初始化，光度损失 + 自适应密度控制（欠重建区克隆/分裂、过重建区剪枝、低透明度剔除）迭代数千步。**训练是分钟级逐场景过程，渲染才是实时的**——"重建结果实时渲染可行、流式实时重建不现实"的分层判断（智驾综述 §6）在 3DGS 侧同样成立：每来一段新视频就要重新优化或增量更新，后者是开放研究问题。

**许可与生态（仓库已核，只链接）**：Inria 原始实现研究/评估免费、商用需明示同意且不可转授；算法本身无专利壁垒 → 独立实现合法，gsplat（Apache-2.0）正是此路径。驾驶变体：Street Gaussians（背景+可优化位姿的跟踪前景）、DrivingGaussian（环视动态复合高斯）、OmniRe（log→城市数字孪生）、PVG（周期振动时间建模、无需物体位姿）——存在性已核、各仓 LICENSE 未逐页（智驾综述 §3）。前馈 3DGS（免逐场景优化）是 2024–2026 的活跃方向（DA3 related work 列举，转述）。

### 1.4 单目深度/相机/运动估计与尺度歧义

**尺度歧义的数学本质**：单张图像下，"5 米外的真车"与"0.5 米外的玩具车"投影完全相同——深度 z 与 s·z 不可区分（§1.1 的 Sim(3) gauge 在单视图的退化）。三条出路：
1. **相对/affine-invariant 深度**（MiDaS/Depth Anything 系）：只学结构不学绝对尺度，评测时与 GT 做尺度（+平移）对齐；跨帧一致性不保证。
2. **metric 深度**（Metric3D 系）：靠内参先验/规范相机空间把尺度"钉"进训练分布——本质是学出来的先验，不是观测。
3. **多视图消歧**：有了基线，三角化恢复相对尺度；绝对尺度仍需外部锚（标定物/IMU/轮速）。VGGT 的 GT 尺度归一化、π³ 的"全序列共享尺度因子 + ROE 求解器对齐"都是这条路的训练侧实现。

**相机估计**：前馈模型直接回归位姿编码（VGGT 9 维 = t3+四元数4+FoV2，主点居中假设——机制性近似，深报 §2.4 已核）；DA3 用逐像素 ray map（原点+方向，6 通道）隐式表达相机，避开旋转矩阵正交约束（官方论文已核）。**运动估计**：VGGT track head（CoTracker2 式相关度金字塔+迭代精化，不假设时间顺序）给跨帧点轨迹；GVHMR 给世界坐标人体运动（重力-视线坐标系逐帧回归+相机旋转转回世界系，预处理 VO 是瓶颈：46 s vs 前向 280 ms，卡已核）。**置信度语义在这条线上最丰富也最混乱**：VGGT 深度/点图 conf 是 [1,∞) precision 型损失权重、轨迹 conf 是 [0,1] sigmoid 族、camera 无 conf（深报 §2.6/§4 已核）；π³ conf 是 BCE 训练的误差阈值二值近似、Pi3X 改为连续质量分（官方 README 已核）——**不同生产者的 confidence 数值域与语义不同族，入契约必须分域标注/归一化**（关联性结论，六方向整合 §2 矩阵同口径）。

### 1.5 智驾视觉管线 I：AVM 鱼眼拼接的几何本质

**量产 AVM/3D-AVM 不是三维重建**（智驾综述 §1，TI 白皮书 PDF 逐句核验 ✅，只链接不复述细节）。几何链条四步：
1. **鱼眼标定**：4 个 ~190° hFOV 鱼眼覆盖 360°；畸变模型三套（OpenCV Kannala-Brandt 多项式 / Mei 统一球面 / DriveWorks F-Theta 等）+ 外参标定。
2. **IPM 逆透视变换**：畸变校正 + 透视变换**合并成一张 LUT**；核心假设 = **平地**。地面不平/物体有高度 → 投影伪影。
3. **光度对齐与拼接**：各相机 AE/AWB 差异 → 逐通道 tone mapping；重叠区 alpha-blending（blending LUT 标定时一次生成）。
4. **3D 视图 = 预定义 bowl 曲面**（车近处平面、远处上翘）+ mesh table 预映射鱼眼像素——启动时一次生成、逐帧 GPU 纹理映射复用。**是"车模+曲面投影"，不是真三维**。

**置信度隐藏点（T6 最重要的契约语义教材）**：AVM 的全部几何承诺（平地、静态世界、固定外参、固定光度）都固化在**标定时刻的一次性假设**里，运行时没有任何置信度输出。鬼影（运动物体在重叠区被双份投影）与近旁车辆拉伸正是假设失效的表现——量产管线无专项处理，学术缓解 = 深度自适应 bowl 形状/运动物体检测（综述 §1）。**"静态先验假设 + 无置信度外泄"与 World Contract 的"显式置信度 + 观测缺失语义"构成精确对照**（关联性，裁决归 ADR-0016）。实时口径已核：4 路 880×1080 鸟瞰 30 fps、bowl mesh 刷新 21 ms @750 MHz DSP；端到端 ms 延迟无一手来源（未核）。

### 1.6 智驾视觉管线 II：BEV/Occupancy 是感知中间态，不是契约状态

- **LSS**（ECCV 2020）：Lift（每像素深度分布×图像特征→视锥特征）→ Splat（pillar pooling 投到 BEV 网格）→ Shoot。深度分布是**学出来的软假设**，不是测量。
- **BEVFormer**（ECCV 2022）：BEV query + spatial cross-attention 跨相机采样 + temporal self-attention 递归融合历史 BEV；nuScenes test 56.9% NDS（综述逐页核验 ✅）。
- **Occupancy**：稠密体素占用+语义替代 3D 框（Tesla AI Day 2022 提出；Occ3D/OpenOccupancy 学术基准）。
- **在线建图 MapTR**：地图元素=点集合+置换等价建模，纯相机 25.1 FPS @3090（综述逐页核验 ✅）。

**为什么它们是"中间态"**：BEV 特征图/体素/矢量线的生命周期绑定单次推理——无跨 tick 身份持久性、无置信度语义外泄、不可复现（依赖模型权重与随机性）、不可编辑回放。它们证明"多相机→结构化状态"是工业共识，但产物不是可仲裁、可复现的世界状态。**这个落差 = OmniWorld 楔子的证据**（综述 §2 结论，六方向整合 D5 复用；本文只确认其原理成立，不裁决）。对照 §1.2：重建产物至少是"测量候选"，BEV 产物连测量候选都不是——它是任务嵌入。

### 1.7 工业主攻线：视频→重建→自由视角→闭环仿真

原理链条（综述 §3/§4 已核，只链接）：真实 log →（SfM/前馈几何）→ 静态背景+动态前景分解的神经表示（NeRF/3DGS）→ 自由视角渲染 → 传感器仿真/闭环评测（UniSim：单条 log→闭环多传感器仿真、演员可增删重摆，CVPR 2023 最佳论文；NeuroNCAP：照片级闭环安全测试）。**固有边界：重建只能复现采集轨迹邻域**——自车大幅偏离原轨迹（变道/绕行）后，超出重建范围的视角出现伪影。这正是生成式世界模型（Vista→GAIA-2→X-World/OmniDreams/Waymo WM）在 2024–2026 接棒的动机：用生成补全重建的外推盲区（小鹏官方新闻稿对 3DGS 路线局限的表述与 OmniDreams 论文动机一致，均已核）。**混合形态已出现**：OmniDreams 的 Diffusion Fixer 用法——重建给几何精度、生成模型修复外推伪影（论文 §衍生应用，arXiv HTML 经检索获取；知乎转述细节未逐页）；与 Marionette"显式状态→确定性几何→扩散外观"（六方向整合已核）同构。

**三个对 T6 判断关键的更新**：
1. **VGGT-Ω 的端到端显存表改变了 8 GB 可行性分析的基准面**：旧"≤20 帧 5.58 GB 档"是 VGGT **修复前、仅特征骨干**的数字；Ω 的新表**含模型权重与全部推理缓冲**，1 帧就要 6.02 GB、25 帧 7.80 GB——在 A100 上 8 GB 也只够 ~25 帧量级，跨 GPU 外推到 4060 Laptop 8 GB 仍不成立，**本地实测仍是唯一裁决依据**（§6）。
2. **register attention 买的是速度不是显存**：论文明确 flash attention v2 下注意力矩阵本就不物化，峰值显存由帧比例激活主导（Ω 论文，经第三方精读卡片获取，**转述**——但与 VGGT 深报"修复只砍输出缓存、平方复杂度不变"的推断一致）。
3. **动态场景成为前馈重建的标配能力**：Ω 只预测深度+相机（无 ray map、无运动掩码）即解耦相机运动与场景运动，官方称静态/动态双 SOTA；π³ 训练集含内部动态数据。VGGT 时代"大幅非刚性失败"的边界正在被推进——但**鱼眼/全景仍是 VGGT 官方承认的分布外输入**（卡已核；Ω/π³/DA3 对鱼眼的官方口径未查，**未核**）。

### 2.2 3DGS 生态

本体与许可见 §1.3（Inria NC / gsplat Apache-2.0，仓库已核）。生态动向：① 驾驶场景变体四件套（Street Gaussians/DrivingGaussian/OmniRe/PVG）已成"log→数字孪生"标准参照（综述已核）；② 前馈 3DGS（免逐场景优化）与几何基础模型合流——DA3 官方证明"几何基础模型微调 NVS 头 substantially 优于专门模型（DepthSplat 等）"（论文已核）；③ 工业界开始把 3DGS 重建仿真当**基线而非终点**：小鹏官方新闻稿明确以"3DGS 难以外推采集轨迹外场景"为 X-World 的立项动机（已核）；NVIDIA OmniDreams 用扩散模型修复 3DGS/NeRF 外推伪影（Diffusion Fixer，论文已核）。**3DGS 的角色正从"重建终点"移向"几何底座+生成补全"混合管线的确定性半边**（趋势归纳，依据上述已核事实；不裁决）。

## 3. 关键文献精读（3 篇）

### 3.1 VGGT: Visual Geometry Grounded Transformer（CVPR 2025 Best Paper，arXiv 2503.11651）

- **问题**：SfM/MVS 多阶段迭代管线脆弱且慢；DUSt3R 系仍需测试时全局对齐。能否一次前馈直出全部几何？
- **方法**：DINOv2 patchify + 每帧 camera/register token + 24 层交替（帧内/全局）注意力 + 四头（camera 9 维编码迭代精化 / DPT 深度 / DPT 点图 / CoTracker2 式轨迹）；GT 归一化到首相机系消 gauge；aleatoric 损失 `γ·L·conf − α·log conf` 让置信度从损失里长出来。17 类数据集、64×A100×9 天。（机制细节全部见[深报](../deep/2026-11-05-vggt.md) §2，此处不重复。）
- **关键结果**：10 帧 0.2 s vs COLMAP ~15 s；Re10K AUC@30 85.3（纯前馈）→ 93.5（+BA）；IMC 上纯前馈不敌优化式 SOTA、+BA 后 84.91 拿下 SOTA（深报已核）。
- **局限**：鱼眼/全景不支持、极端旋转退化、大幅非刚性失败；全局注意力显存随帧数陡增；camera 无置信度；conf 无官方校准主张；每场景一次前馈、无流式接口。
- **与 OmniWorld 的关联**：四类输出与 World Contract 的 identity（轨迹）/confidence（逐像素）天然同构，是 L1"几何观测生产者"的最对位参照；gauge 钉死首帧 ⇒ canonical frame 所有权必须在引擎侧；conf 两族语义不同 ⇒ 契约 confidence 域需分域（深报 §4 已论证，本文确认其原理基础仍成立）。**后继 Ω 已发布（§2.1），适配器锚定对象需重评——这是知识基线层面的更新，不是裁决。**

### 3.2 3D Gaussian Splatting for Real-Time Radiance Field Rendering（SIGGRAPH 2023，arXiv 2308.04079）

- **问题**：NeRF 质量高但光线步进渲染慢；能否兼得照片级质量与实时渲染？
- **方法**：各向异性 3D 高斯显式表示 + 可微 tile-based 光栅化（投影→分 tile 深度排序→α-blending）+ 自适应密度控制（克隆/分裂/剪枝）；从 SfM 稀疏点初始化，光度损失逐场景优化。（原理展开见 §1.3；论文+Inria LICENSE 逐页核验见[智驾综述 §3](../2026-11-08-autonomous-driving-visual-survey.md)。）
- **关键结果**：1080p 实时（≥30–100+ fps，论文口径）；质量对标当时 NeRF SOTA（综述已核口径）。
- **局限**：逐场景分钟级优化；依赖输入位姿质量；存储随场景规模增长；动态场景需扩展（驾驶四件套的动机）；视角外推超出观测覆盖即伪影（小鹏/ NVIDIA 官方均以此为生成式接棒动机，已核）。Inria 实现非商用（LICENSE 逐字已核）。
- **与 OmniWorld 的关联**：L4 表现后端的候选表示（显式、可编辑、与"确定性几何+生成式外观"混合架构兼容）；"重建结果实时渲染可行、训练离线"给出 8 GB 分层的渲染侧依据；gsplat Apache-2.0 独立实现路径与参考模式零依赖承诺的接缝已有队列登记（只链接，不裁决）。

### 3.3 VGGT-Ω（CVPR 2026 Oral，arXiv 2605.15195）

- **问题**：前馈重建能否像 LLM 一样**可预测地规模化**（模型×数据 → 误差单调下降）？VGGT 的多头架构与训练显存是规模化瓶颈。
- **方法**：① 单稠密头（只解码深度+置信度）但保留点图/匹配多任务监督——"监督冗余目标、只解码一个"；② register attention：25% 全局注意力层换成仅 per-frame registers 跨帧交换，场景信息经帧内块再分发；③ DPT 高分辨率卷积层换 MLP+pixel-shuffle；④ 相机头去掉迭代精化、Huber→L1；⑤ DINOv3 初始化；⑥ VLM 门控+COLMAP 验证+分类器过滤的数据标注管线（~40M 候选视频→~200K 动态+~600K 静态序列）；⑦ EMA 师生自监督利用无标注视频。训练 128×96GB H100、0.2B–10B 四档。（机制细节经官方 README+摘要已核；标注管线/消融数字经第三方精读卡片，**转述**。）
- **关键结果**：训练显存 ≈ VGGT 30%、15× 监督数据；Sintel 相机精度 +77%（官方摘要已核）；点误差随模型 1B→10B（0.107→0.046）与数据 10⁴→10⁶（0.275→0.129）单调下降（第三方卡片转述论文 Fig.1）；**registers 冻结即可提升 VLA 策略（LIBERO）并支持语言对齐**——"重建是空间理解的可规模化代理任务"（官方摘要主张，已核）。
- **局限**：register attention 有小幅精度代价（0.071→0.073，转述）；推理显存仍随帧数线性增长（端到端表：500 帧 43.15 GB）；权重 gated；10B 档远离消费级硬件；复现检查点 2026-09 才补发（原检查点曾有可复现性质疑，官方 README 自述，已核）。
- **与 OmniWorld 的关联**：① "几何观测生产者"座席的锚定对象候选更新（Ω vs VGGT，许可/接口/8 GB 实测三件未做，§6）；② registers 作为"场景紧凑表征可被下游策略消费"的官方证据，与 L1→L3 的观测契约同构（关联性）；③ 其"保守过滤的伪真值胜过大而噪"的标注哲学（Sintel 对照 96.4 vs MegaSaM 62.1 AUC@30，转述）与评测侧"真值质量优先"的方法论互证；④ 端到端显存表是 8 GB 可行性讨论的**新基准面**（§2.1）。

## 4. 开放问题（知识层，非裁决）

1. **前馈重建的置信度校准**：VGGT conf 无官方校准主张（深报 UNVERIFIED-1）；π³→Pi3X 把 conf 从"二值掩码近似"改成"连续质量分"（官方自述）——说明该族置信度语义仍在漂移。跨生产者、跨版本的 confidence 可比性没有任何标准，契约侧归一化/校准只能引擎自建（与六方向 D2"契约⑦引擎自建"结论互证）。
2. **流式/增量重建**：VGGT 族无增量接口；Ω 的 register attention 改善的是批处理速度。CUT3R/VGGT-SLAM 等流式后继在 DA3 related work 中被列举（转述），其精度-漂移-显存三角未深查——"流式实时重建不现实"的 v1 判断在原理层仍成立，但**学术边界在移动**，需盯防。
3. **动态场景的 identity**：Ω/π³ 支持动态场景指"几何重建不退化"，不等于"跨帧实体身份"——track head 的身份仍限单次调用内（深报 §4），跨调用身份注册表依然是引擎侧责任。
4. **重建 vs 生成的分工边界**：Diffusion Fixer/Marionette 式混合管线里，"哪些像素是测量、哪些是想象"没有显式标记——这正是置信度契约要回答的问题，但学术界目前不输出该语义（观察归纳）。
5. **鱼眼/全景的前馈支持**：VGGT 明确不支持；Ω/π³/DA3 官方口径未查（未核）。AVM 复现若走前馈路线，鱼眼是硬缺口；若走传统标定+LUT 路线则无此问题（综述 §1 已核）。
6. **metric 尺度的可信度**：Pi3X"近似 metric 尺度"（官方措辞 approximate）与 DA3 的尺度处理未定量核验——绝对尺度进入世界状态前的校准协议是空白。
